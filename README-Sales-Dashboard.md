# 💼 Sales Data Dashboard (Power BI)

A Power BI file built on the classic "Classic Models" sales dataset — a widely used sample dataset (scale-model car distributor) for practicing BI, analytics, and dashboarding.

![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat&logo=powerbi&logoColor=black)
![Status](https://img.shields.io/badge/status-in%20progress-yellow)

## 📊 Overview

This file connects to and models the `classicmodels` sales dataset inside Power BI, ready for building out sales visuals (revenue by region, top products, customer trends, etc.).

> **Note:** As currently uploaded, the report canvas doesn't yet contain built-out visuals — this is the data-modeling stage. If you've since added charts/pages in Power BI Desktop, re-save the `.pbix` and update this README with the finished report details (page names, KPIs, screenshots) before publishing.

## 🗂️ Data

- `classicmodels_sales_data_for_power_bi` — flattened sales transaction data (orders, products, customers) from the Classic Models dataset.

## 🛠️ Tools Used

- Power BI Desktop
- Power Query / DAX

## 🚀 How to Use

1. Download `Sales_Dashboard.pbix`.
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
3. Explore or extend the data model to build your own visuals.
